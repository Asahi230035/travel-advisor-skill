# Security and responsible reporting

Travel Advisor Skill is an instruction-led skill and offline helper library. It does not directly access provider accounts or perform bookings. A host agent may have its own tools and permissions, so prompt-injection resistance and explicit approval for side-effecting operations remain essential.

**Please do not post** real booking IDs, access credentials, passport details, addresses, private itineraries, payment information, or exploits involving private accounts in public GitHub issues.

Before a public repository maintainer establishes a private reporting address, avoid sending secrets to unverified addresses. For non-sensitive issues, use GitHub Issues. For sensitive findings, use GitHub's private vulnerability reporting feature **if the repository owner enables it**; otherwise request a safe reporting channel without disclosing exploit details.

When filing a report, include the affected file, minimal synthetic reproduction, potential impact, and expected behavior.
